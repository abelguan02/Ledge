- 设计画布的公开源码位于下方 `design/` 目录；私人画布入口不包含在仓库中。
- 画板源码：[`design/concept-2026-10-28/`](../design/concept-2026-10-28/)。这些是设计画布专用格式的 HTML（`.dc.html`），离开画布不能直接运行，但颜色、尺寸、文字都能从里面原样读到。
- 产品定义与已确认／建议／待定的划分，以 [产品简报](PRODUCT_BRIEF.md) 为准。本文所有视觉数值都是〔建议〕，用户确认前可以调整。
- **2026-10-28 定稿**：用户选定原生玻璃，并改为“任何格式都能放、能放心清空的材料暂存区”。**开发以第 9 节为准**；第 1–7 节是过程稿，只在第 9 节引用时有效（例如第 5 节的玻璃材质参数）。

## 1. 视觉基础

只画了深色。浅色版本待设计，原则相同：中性底色，没有光晕。

| 用途 | 值 |
| --- | --- |
| 面板底色 | `#111113` |
| 卡片底色 | `#1B1B1F`，描边 `rgba(255,255,255,0.06)` |
| 卡片内嵌区（文字摘要、文件图标底） | `#232328` |
| 主文字 | `#F5F5F7` |
| 次要文字 | `#A1A1A6` |
| 输入框占位文字 | `#8E8E93` |
| 次要按钮底 | `rgba(255,255,255,0.08)` |
| 主按钮 | 底 `#F5F5F7`，字 `#111113` |
| 选中描边 | 2px `#F5F5F7`，左上角白色圆形勾 |
| 面板圆角 | 朝屏幕内侧 22–24px，贴屏幕的一侧为直边 |
| 卡片圆角 | 14px；缩略图 10px |
| 字体 | 系统字体（SF／苹方）；数字和代码用等宽（SF Mono） |

**颜色只用在两处**（用户 2026-10-28 确认：颜色只做指示灯和类别区分，面板上不要光团）：

1. 细线这盏指示灯（见第 2 节）。
2. 材料类型的 6px 小圆点：图片 `#BF5AF2`、文字 `#64D2FF`、文件 `#FF9F0A`。

除此之外不出现彩色，不使用光晕、柔光、彩色渐变底。

## 2. 细线（画板 `Main.dc.html`）

贴在屏幕边缘，宽 4px、高 96px，贴边一侧直角，内侧圆角 2px。只表达当前收集区的状态：

| 状态 | 何时 | 样子 |
| --- | --- | --- |
| 平静 | 没有事要处理 | `rgba(255,255,255,0.28)` 静止 |
| 在动 | 有东西正在处理 | 平静底色上，一段 28px 的白色渐变从上往下流动，周期 1.6 秒 |
| 需要你看 | 处理已完成，结果还没看过 | 整条变成 `#F5F5F7`，透明度在 0.55–1 之间呼吸，周期 2.4 秒 |
| 出错 | 处理失败 | 同“需要你看”，颜色换成 `#FF453A` |

多种情况同时存在时，优先级：出错 > 需要你看 > 在动 > 平静。系统开启“减少动态效果”时，去掉流动和呼吸，只保留静态颜色。

## 3. 投放面板（画板 `DropImage.dc.html`、`DropText.dc.html`）

拖着东西靠近屏幕边缘时，细线展开成投放面板：300×400，贴屏幕边。面板只做投放这一件事（用户确认）。

- **顶行**：材料类型小圆点 + 拖入内容的简述（“3 张图片”“一段文字”），右侧是当前收集区的名字（次要文字色）。
- **大格**（占满剩余高度）：“放进来”。只收进来，不做任何处理。
- **小格**（一行两个，高 64px）：适合这类材料的直接动作，根据拖动内容现场生成：
  - 图片：压缩、识别文字
  - 文字：翻译、解释
  - 其他文件：没有小格，只有大格
- 鼠标悬停的格子：描边变为 1.5px `rgba(245,245,247,0.6)`，底色 `rgba(255,255,255,0.07)`。其他格子：描边 1px `rgba(255,255,255,0.10)`。
- 松手即执行，不弹确认。直接动作松手后，材料同样会放进当前收集区，结果作为新材料放在它旁边。
- 面板上没有说明文字、没有灯光。

## 4. 工作台

展开后的主界面，560×700，贴屏幕边。

### 4.1 总览（画板 `Workbench.dc.html`）

- **头部**：这件事的名字（22px 粗体）+ 下拉箭头（点它切换到别的事）；下面一行是备注（13px 次要色）；右上角是收起按钮。
- **统计行**：“6 样材料 · 1 样待取 · 1 样处理中”（12px 次要色）。
- **材料网格**：三列，间距 12px。每张卡片：上面是 92px 高的预览（图片缩略图、文字前几行、文件图标），下面是类型小圆点 + 名字。
- **结果卡片**：预览右上角有白底黑字的“待取”标签；名字下面写明来源，例如“由上一张压缩”。被拖出或复制后，“待取”消失。
- **处理中的卡片**：预览变暗，底部有进度条和“压缩中 62%”（等宽数字）。
- **底部提示**：没有选中任何材料时，居中显示“选中材料来处理 · 拖出去即取走一份副本”。

### 4.2 选中材料（画板 `WorkbenchSelected.dc.html`）

- 选中的卡片显示白色描边和勾；和已选材料类型不同的卡片降到 45% 透明度，表示当前动作对它们不适用。
- 底部提示换成**动作条**：
  - 第一行：类型小圆点 + “已选 2 张图片”；右侧是当前参数摘要（例如“1600 宽 · WEBP · 82%”），点击展开参数。
  - 第二行：可用动作按钮，一行最多四个。最常用的动作为主按钮，其他为次要按钮。
- 文字材料的动作：翻译、解释、总结、润色、改写。图片的动作：压缩、调整尺寸、转格式、识别文字。

### 4.3 文字处理结果（画板 `WorkbenchAnswer.dc.html`）

- 头部左上是返回（“‹ 周报材料”），回到总览。
- **原文卡片**：类型小圆点 + “原文 · 来源”，下面是原文。
- **动作切换**：一排胶囊按钮（翻译、解释、总结、润色、改写），当前动作为白底黑字；切换后重新处理。
- **回答**：14.5px、行高 1.7 的正文；代码和示例用等宽字体。
- **底部**：“继续追问…”输入框，以及“复制”“存为材料”两个按钮（存为材料是主按钮）。存为材料后，回答成为这件事里的一张文字卡片，连着原文。

## 5. 方向二：原生玻璃（画板 `Glass*.dc.html`，待用户选择）

2026-10-28 用户反馈第一版“整体很平”，希望有苹果原生软件的感觉。方向二保留第 2–4 节的结构，改变的是材质、层次和文字入口。**用户选定方向前，不要按第 1 节或本节任何一方开工界面。**

### 5.1 文字入口：粘贴优先

用户 2026-10-28 指出：文字更多是复制粘贴，不是拖拽。因此：

- 工作台头部下方常驻一个输入框：“粘贴或输入要处理的文字”，右侧显示 `⌘V` 键帽。
- 面板打开时按 `⌘V`，剪贴板文字变成一张卡片（画板 `GlassPaste`）：上面写“剪贴板 · 刚刚复制 · N 字”，中间是原文，下面是动作胶囊（解释、翻译、总结、润色、改写）和“只放进来”。按 ↩ 用默认动作处理。
- 只在用户按 `⌘V` 或点击时才读取剪贴板。〔待验证〕较新的 macOS 在应用程序化读取剪贴板时可能弹出隐私提示，打开面板时不要自动读取剪贴板内容；如需提示“剪贴板里有文字”，先验证系统提供的只检测类型、不读内容的方式。

### 5.2 材质

- 面板是浮起的毛玻璃，离屏幕边 12px，四角圆角 26px：底色 `rgba(28,28,32,0.58)` + 背景模糊 36px、饱和度 180%，内描边 0.5px `rgba(255,255,255,0.16)`，顶部 1px 高光 `rgba(255,255,255,0.18)`，外阴影 `0 30px 80px rgba(0,0,0,0.45)`。macOS 实现用系统的 vibrancy 材质（`NSVisualEffectView` 或 SwiftUI `Material`），以系统观感为准，不必逐值照抄。
- 颜色来源变成：用户自己的桌面（透过玻璃）+ 材料本身的内容（缩略图）。应用自身仍然只有指示灯和类型小圆点两种颜色。
- 浮动工具条和追问栏是第二层玻璃：`rgba(48,48,54,0.62)`，模糊 30px，圆角 22–24px。

### 5.3 字体与层次

- 标题 26px 粗体，字距 -0.4px；次要文字用系统的 secondary label（深色约 `rgba(235,235,245,0.6)`）。
- 内层圆角与外层同心：面板 26 → 输入框 14 → 缩略图 12。

### 5.4 材料以“物件”呈现

- 图片：真实缩略图，圆角 12，有投影，没有卡片底；名字和“格式 · 大小”居中写在下面（类似访达的图标视图）。
- 文字：一张米白色便签（`#FBFAF6`，深色字），一眼能分出是文字。
- 文件：系统风格的文档图标（PDF 带红色标签）。
- 待取：缩略图右上角白底黑字“待取”。处理中：缩略图变暗，中间一个圆环进度。

### 5.5 选中与动作

- 选中项：背后出现圆角浅色底 `rgba(255,255,255,0.14)`，文件名换成系统强调色（`#0A84FF`）的胶囊，和访达一致。〔建议〕这会在两处颜色之外多用一个系统强调色，需要用户确认；不接受的话改用白色胶囊。
- 不适用当前动作的材料降到 40% 透明度。
- 动作出现在底部浮动的玻璃工具条：左侧类型小圆点 + “2 张图片”，右侧是图标在上、文字在下的动作按钮（压缩、尺寸、格式、识别文字）。参数在点按后以弹出框调整（未画）。

### 5.6 文字处理结果

- 头部左上“‹ 周报材料”返回；标题是当前动作（26px 粗体），右侧是分段控件切换动作。
- 原文用便签样式放在上方；回答 15px、行高 1.68；示例代码放在并排的两个内嵌框里。
- 底部浮动玻璃栏：追问输入框、复制按钮、“存为材料”主按钮。

## 7. 方向四：Claude 感（画板 `Claude*.dc.html`，待用户选择）

2026-10-28 用户希望界面“一看就像 Claude 团队出品”。做法是沿用 Claude 产品的设计语言：暖色、留白、衬线标题、以输入框为中心。**不使用 Claude／Anthropic 的标志、名称或星芒图形**，也不能让人误以为这是 Anthropic 的官方产品；它只是气质相近的个人工具。

### 7.1 颜色（暖灰体系，不用冷灰）

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 面板底 | Ivory `#FAF9F5` | `#262624` |
| 卡片、输入框 | `#FFFFFF` | `#30302E` |
| 主文字 | Slate `#141413` | `#FAF9F5` |
| 次要文字 | `#73726C`／`#5E5D59` | `#9C9A92`／`#B0AEA5` |
| 描边 | 0.5px `rgba(31,30,29,0.15)`，强调时 0.3 | 0.5px `rgba(222,220,209,0.15)` |
| 浅色块（图标底、用户消息气泡） | Oat 系 `#F0EEE6` | `#3D3D3A` |
| 唯一强调色 | Clay `#D97757`：发送按钮、进度、待取、当前选中的动作 | 同左；文字上用 `#E8977A` |

颜色仍只做“指示”：Clay 只出现在需要你注意或可以按下的地方。材料类型不再用彩色小圆点，靠缩略图和图标区分。

### 7.2 字体

- 标题（这件事的名字、“材料”）和 AI 回答正文用衬线：`'Anthropic Serif', 'Songti SC', Georgia, serif`。这是最像 Claude 的一点：回答读起来像文章而不是系统提示。
- 界面文字用无衬线：`'Anthropic Sans', -apple-system, 'PingFang SC', system-ui, sans-serif`；代码用等宽。
- 标题 30px、字重 400；正文 15–16px；说明 12–14px。不加字距。Anthropic 字体不对外提供，正式实现时用系统字体（宋体／苹方）呈现即可。

### 7.3 结构

- **总览**（`ClaudeOverview`、`ClaudeDark`）：上方小字“当前这件事” + 衬线大标题 + 备注；下面是 Claude 式输入框（白底、圆角 20，左下“+”添加文件和默认动作选择，右下 Clay 发送按钮，空时变淡）；再下面是材料列表，做成两列“附件卡片”（44px 缩略图或图标 + 名字 + 大小），待取用 Clay 浅底标签，处理中用 3px Clay 进度条。
- **粘贴**（`ClaudePaste`）：⌘V 后，文字以“粘贴的文字 · N 字”小卡片出现在输入框里（右上角可移除），下面可以写补充要求；输入框下方一排带图标的动作按钮，当前动作用 Clay 描边；还有“只放进来”。
- **结果**（`ClaudeAnswer`）：像一次对话。原文作为右侧的浅色气泡，下面写“解释 · 粘贴的文字”；回答用衬线正文、左对齐，示例放在两个并排的浅色代码框；回答下方是复制、重新处理、“存为材料”；底部是“继续追问…”输入框。

## 9. 定稿方向：原生玻璃 · 空白画布（画板 `Canvas*.dc.html`，当前以此为准）

2026-10-28 用户选定原生玻璃（第 5 节的材质、字体、圆角规则继续适用），并按简报第 0、2 节的新定位重画：任何格式都能放、一个面板只显示一个收集区、像空白画布一样干净、材料自由摆放。**第 1、4、6、7 节以及第 5 节里与本节冲突的内容（大标题、备注、粘贴输入框常驻、统计行、网格排列）全部作废。**

### 9.1 面板外壳（所有画板相同）

- 面板**从屏幕边长出来**，不是独立浮起的窗口〔用户确认 2026-10-28〕：贴屏幕的一侧是直边、紧贴屏幕边；朝屏幕内的两个角圆角 26；与屏幕边相接的上下两处各有一段半径 24 的内凹圆弧，让面板像从边缘“长”出来。尺寸 520×720；毛玻璃材质参数同 5.2（5.2 里“离屏幕边 12px、四角圆角”的说法作废）。阴影只朝屏幕内侧投。
- 停靠位置〔用户确认 2026-10-28〕：可以在设置的“通用”页（9.19）选右侧（默认）、左侧或上方（画板 `CanvasEdges`）。左侧是右侧的镜像，收起按钮箭头随之反向；上方从菜单栏下方往下长，横向更宽、纵向更矮。〔用户确认 2026-11-01〕保留材料坐标，只调整窗口形状，不自动重新排列材料；需要时平移查看。收起时都退回成所在边上的细线。
- 顶栏高 52px，背景透明，只有三样东西：左边收集区名字（13px 中粗，带小箭头，点击切换）；右边“清空”（12.5px 次要色；收集区为空时禁用变淡）；最右是圆形收起按钮。
- 除此之外，面板上**没有任何固定的文字或控件**。

### 9.2 空白画布（`CanvasEmpty`）

- 收集区为空时，正中只有一行很淡的“拖进来，或按 ⌘V”（`rgba(235,235,245,0.38)`），放进第一样东西后消失。〔建议〕如果用户觉得这行也多余，可以去掉。

### 9.3 任何格式、自由摆放（`CanvasMixed`）

材料以“物件”的样子散放在画布上，大小不完全一致，可以重叠：

| 格式 | 样子 |
| --- | --- |
| 图片 | 缩略图本身，圆角 12，投影，平时不显示文件名（选中或悬停时显示） |
| 文字 | 米白便签 `#FBFAF6`，深色字 |
| 链接 | 深灰玻璃卡片 `rgba(58,58,62,0.88)`：上方网页预览图，下方标题（两行内）+ 地球图标 + 域名（细则见 9.17） |
| 视频 | 封面帧，中间半透明圆形播放按钮，右下角时长（等宽数字） |
| 音频 | 深灰卡片：白色圆形播放按钮 + 波形 + “名字 · 时长” |
| 其他文件 | 系统风格文档图标（按类型带彩色标签，如 PDF 红、XLSX 绿），下方显示文件名 |

拖动时：画布显示 24px 间距的淡点阵；被拖的材料略微放大（1.04）、轻微倾斜、投影加深；松手位置用虚线圆角框预示，松手后吸附到点阵。不拖动时点阵隐藏。新放进来的材料怎样找位置、放满了怎么办，见 9.9。

### 9.4 粘贴文字（`CanvasPaste`）

- 面板打开时按 ⌘V：剪贴板文字直接变成一张便签落在画布上（白色描边表示刚粘贴），下方小字“刚刚粘贴 · N 字”。
- 便签上方浮出一条玻璃胶囊：解释（默认，白底）、翻译、总结、润色、改写，以及“↩ 解释”提示。按回车即处理；点别处胶囊消失，便签留在画布上。
- 其他材料暂时变淡，突出刚粘贴的内容。剪贴板读取规则同 5.1（只在按 ⌘V 时读取）。

### 9.5 选中图片（`CanvasSelect`）

- 选中的图片外圈 3px 系统强调色 `#0A84FF`，下方出现蓝色文件名胶囊；其他材料降到 40% 透明度。〔用户确认 2026-10-28〕选中使用系统强调色蓝色。
- 底部浮动玻璃工具条：“2 张图片” | 压缩、尺寸、格式、识别文字 | 删除（只删除收集区里的副本）。

### 9.6 文字处理结果（`CanvasAnswer`）

- 结果是一张浮在原便签旁边的玻璃卡片，用虚线连着原便签，不离开画布。
- 卡片内：标题（当前动作）+ 关闭；分段控件切换动作；回答正文 13.5px；示例代码并排放在暗色内嵌框；“继续追问…”输入框；复制按钮和“放到画布上”主按钮（把回答变成一张新便签）。
- 关闭卡片不保存回答；需要保留就“放到画布上”。

### 9.7 切换收集区（第一阶段）与铺开（第二阶段）（`CanvasExpanded`）

画板 `CanvasExpanded` 同时画了这两件事，但它们属于不同阶段：

- **切换收集区——第一阶段**〔用户确认 2026-10-28〕。 点顶栏的收集区名字，弹出玻璃菜单：各收集区名字和材料数量，当前的打勾高亮；最下面“新建收集区…”。菜单里每一项可右键改名或删除（删除按 9.10 的清空规则确认）。批量管理和删除见 9.18；右键删除单个收集区也改用 9.18 的确认页。切换时整张画布换成另一个区的内容，面板上仍然只有一个收集区。第一阶段只在面板顶栏切换，不在细线上切换。
- **铺开与缩放——第二阶段。** 铺开后面板变成接近全屏的大画布（示例 1100×852），仍从屏幕边长出；顶栏多一个“收回到屏幕边”按钮，右下角有缩放控件（− 100% +），画布可以在两个方向上自由平移。

### 9.9 新材料放在哪、画布放满了怎么办

〔用户确认 2026-10-28〕第一阶段的规则：

- **找位置**：画布按 24px 点阵划分。拖进画布的材料落在松手处（吸附到点阵，和已有材料重叠超过一半时，就近挪到最近的空位）；用 ⌘V 粘贴或从投放面板放进来的材料，从左上角开始，按“先横后竖”找第一个放得下的空位。
- **画布宽度固定，高度可以往下延伸**：第一阶段的画布宽度等于面板宽度，但高度不固定。当前可见区域里找不到空位时，画布自动往下延伸一段，新材料放在延伸出来的位置，面板随即滚动过去，让新材料可见约 1 秒。面板只允许**纵向滚动**，没有横向滚动，也没有缩放。
- 所以第一阶段**不存在“放不下”**：任何时候放进来都不会被拒绝，也不会被叠到别的材料上。
- 往下滚动时顶栏保持固定、透明，材料从它下面滑过。
- 第二阶段加入二维平移和缩放后，纵向延伸的画布原样保留，只是可以缩小来看全貌。
- 〔用户确认 2026-10-28〕容量规则：
  - 每个收集区总大小上限 5 GB，按副本实际占用计算；
  - 单个材料上限 2 GB；
  - 整台电脑剩余空间低于 10 GB 时，所有收集区暂停接收，避免挤占系统；
  - 不限制材料数量；
  - 收集区菜单里每个区显示已用大小（例如“新应用灵感 · 1.2 GB”），方便决定清空哪个；
  - 上限可在设置的“存储”页调整（9.19）。
- 达到任一上限时，拒绝新放进来的这一样，并在原地说明是哪条上限、现在用了多少；绝不悄悄删除旧材料。

### 9.10 清空：先分清哪些内容只存在于这里

“放心清空”只对有外部原件的材料完全成立。〔用户确认 2026-10-28〕按来源分两类，以下规则全部确认：

| 类别 | 包括 | 清空后 |
| --- | --- | --- |
| 有原件的副本 | 从访达等处导入的文件、图片、视频、音频，且原件当前仍在原位置 | 原件不受影响，可以放心删 |
| 只存在于这里 | 粘贴的文字；从网页等拖入、没有源文件的图片或数据；链接；处理生成的结果（压缩后的图片、识别出的文字、“放到画布上”的回答）；以及原件已经被移动或删除的导入文件 | 清空后就没有了 |

- 清空前的确认框按实际内容说话。例如：“清空‘新应用灵感’？12 样中有 5 样只存在于这里（3 段粘贴文字、2 个处理结果），清空后无法找回。”按钮依次是：取消、先导出这 5 样…、清空。如果全部都是有原件的副本，只写“原件不受影响”，不多做提示。
- “先导出这 5 样…”会让用户选一个文件夹，把这些内容存成文件：文字存为 `.txt`，链接存为 `.webloc`，其他按原格式保存。
- “原件仍在原位置”在确认框弹出时实时检查，不依赖导入时的记录。
- 清空后提供一次“撤销”，在下一次清空、删除收集区或退出应用之前有效。
- 选中几样材料后删除、删除整个收集区，都套用同一套规则。

### 9.11 细线：玻璃小舌片（`LineTabStates`；方案对比见 `LineOptions`）

〔用户确认 2026-10-29〕采用“玻璃小舌片”方案（画板 `LineOptions` 中的 B）。它取代本节此前的 5×96 半透明白线（`FinalLine`），也取代 2026-10-29 实现的 8×96 深灰加黑边细条。改动原因：用户反馈原白线在白色应用前完全看不见，而深灰实心条又和玻璃面板风格不一致。

**形状**：面板本身的缩小版，从屏幕边长出来。
- 主体宽 14、高 64，竖直居中；贴边一侧是直边，内侧圆角 6。
- 上下各带一段半径 8 的内凹圆弧，和面板（9.1）、投放面板（9.12）是同一种轮廓。可以直接复用面板的边缘形状，参数为圆弧 8、圆角 6，整体外框 14×80。
- 停靠在左侧时左右镜像；停靠在上方时旋转为横向 64×14，把手也改为横向。

**材质**：不随系统深浅色变化。舌片下面是别的应用，跟系统外观无关。
- 底色为深色玻璃 `rgba(44,44,50,0.62)`，加背景模糊和饱和度提升。macOS 上用深色 vibrancy 材质，再叠一层深色，以系统观感为准。
- 〔用户确认 2026-10-29，真实屏幕并排选择〕整个玻璃底层组的不透明度为 0.62，包含 vibrancy 和上述深色叠色；把手与细亮边不跟着降低透明度。仅给深色叠色设置 0.62 会让原生材质仍接近不透明，因此以整组透明度控制最终观感。
- 轮廓：内侧 0.5px `rgba(255,255,255,0.28)` 亮边（上下边约 0.22／0.12）。
- 投影 `-1px 0 4px rgba(0,0,0,0.18)`〔用户确认 2026-10-29，选定 0.62 小投影版，取代初稿 -2px／10px／0.22〕。只用柔和投影，不用实心黑边。
- 不读取、不采样屏幕内容。

**把手**：状态全部由舌片中间的一根把手表达，舌片本身不变色。
- 尺寸 3×28，圆角 1.5，在舌片里水平、竖直都居中。

| 状态 | 何时 | 把手的样子 |
| --- | --- | --- |
| 平静 | 没有在处理的东西 | `rgba(255,255,255,0.88)`，静止 |
| 在动 | 有东西正在处理 | 底色降到 `rgba(255,255,255,0.4)`，一段 14px 的白色渐变从上往下流，1.6 秒一圈 |
| 需要你看 | 处理完成，结果还没看过 | 纯白，透明度在 0.55–1 之间呼吸，周期 2.4 秒；打开面板看过后回到平静 |
| 出错 | 处理失败 | `#FF453A`，同样呼吸；打开面板，在出错的材料旁说明原因 |

- 状态优先级不变：出错 > 需要你看 > 在动 > 平静。
- “减少动态效果”开启时，不流动、不呼吸，只换把手颜色。

**交互**：
- 点击感应区保持 48×160，以舌片为中心靠边。
- 鼠标悬停时，舌片向外多伸出 4px（0.15 秒，缓出），提示可以点开；“减少动态效果”时不伸出。
- 点开或拖近时，舌片沿屏幕边长成完整面板或投放面板。完整展开动画仍属第 10 节未设计项，暂时可以直接切换。

### 9.12 投放面板（`FinalDropImage`、`FinalDropFile`）

- 拖着东西靠近停靠的屏幕边时，细线长成 300×420 的投放面板，同样从屏幕边长出（直边 + 内凹圆弧，圆弧半径 22），玻璃材质同 9.1。
- 顶行：“3 张图片 → 新应用灵感”（数量和类型用文字说明，不用色点）。
- 大格“放进来”占满剩余高度；鼠标悬停的格子底色变为 `rgba(255,255,255,0.16)`，内描边 1.5px `rgba(255,255,255,0.7)`。
- 小格（一行两个，高 64）按拖动内容生成：图片 → 压缩、识别文字；文字 → 翻译、解释；其他文件（PDF、表格、文档、视频、音频等）在对应功能做出来之前没有小格，只有一整块“放进来”。
- 松手即执行；放进来的位置按 9.9 找空位。拖离屏幕边则缩回细线，不放入任何东西。

### 9.13 浅色模式（`FinalLight`）

- 面板玻璃：`rgba(250,250,252,0.62)` + 背景模糊 36px、饱和度 180%；内描边 0.5px `rgba(0,0,0,0.08)`，顶部高光 `rgba(255,255,255,0.9)`；外阴影 `-24px 24px 70px rgba(0,0,0,0.16)`。
- 文字：主 `#1C1C1E`，次要 `rgba(60,60,67,0.6–0.75)`。
- 链接卡、音频卡改为 `rgba(255,255,255,0.9)` 白底，深色字；音频播放按钮改为深底白三角，波形用深灰。
- 便签 `#FFFDF6` 加 0.5px 描边；照片、视频本身不变，投影减弱到约 0.12–0.16。
- 收起等圆形按钮底色 `rgba(0,0,0,0.06)`。跟随系统切换浅色／深色，切换时不重建画布、不改变位置。

### 9.14 清空确认（`FinalClear`）

- 点“清空”后，画布盖上一层 `rgba(10,10,14,0.5)` 的暗色，中间弹出玻璃确认框（400 宽，圆角 22）。
- 内容按 9.10：标题“清空‘新应用灵感’？”；正文写明有几样只存在于这里，下面用一个小列表按类别列出数量（粘贴的文字、处理生成的结果、没有源文件的拖入内容、链接、原件已不在的导入文件，数量为 0 的类别不列）；再用一行小字说明其余是副本、原件不受影响，以及清空后可以撤销一次。
- 按钮竖排：清空（红色 `#FF453A`，破坏性操作）、先导出这 N 样…、取消。按 Esc 等于取消；回车不会触发清空。
- 如果全部是有原件的副本：不显示列表，正文只写“这 N 样都是导入文件的副本，原件不受影响”，按钮只有“清空”和“取消”。

### 9.15 卡片尺寸（第三阶段，`CardResize`）

〔用户确认 2026-10-29〕按设计方修改意见补画。本节取代 `PHASE3_KICKOFF.md` 第 2 节的建议。

- **只改显示大小**：不改图片像素、文件内容或导出的副本。新尺寸随画布保存，重启后保留。
- **入口**：只在单选时出现把手。把手画在蓝色选中轮廓的右下角，是一个白色直角标记（16×16、线宽 3、外角圆角 7，带轻微投影）。感应范围 16px，大小不随画布缩放变化。多选时不显示。
- **哪些能调**：
  - 图片、视频：锁定当前比例。
  - 文字、链接：宽高可以分别调整，字号不变，随宽度重新换行。
  - 文件、文件夹、音频卡：保持默认大小，不显示把手。
- **范围**：宽、高都在 96–480 之间（4–20 格）。文字卡和链接卡的下限为宽 144、高 96。普通面板和铺开画布用同一套上下限。
- **吸附**：尺寸默认吸附 24px 点阵，和位置吸附一致；按住 ⌥ 时自由调整。
  - 〔用户确认 2026-10-29〕图片／视频锁定比例时，拖动主轴吸附 24，另一边按比例计算，不要求宽高同时落在点阵上。
- **拖动时**：
  - 显示拖动点阵，原尺寸用白色虚线框标出；
  - 光标旁显示等宽字体的尺寸读数，例如“240 × 200”；
  - 光标为斜向缩放箭头；
  - 按 Esc 取消本次调整，回到原尺寸。
- **与邻近卡片**：卡片变大后可以压住邻近卡片，邻近卡片不自动让位，后调整的卡片显示在上层。
- **文字卡比内容矮时**：底部 28px 渐隐，提示下面还有内容。双击仍打开全文。
- **恢复**：右键菜单增加“恢复默认大小”，只在尺寸被改过时出现。

### 9.16 堆叠（第三阶段，`CardStack`）

〔用户确认 2026-10-29〕按设计方修改意见补画。本节取代 `PHASE3_KICKOFF.md` 第 3 节的建议。原则：堆叠只用来把相关材料收拢在一起，不起名字、不嵌套；加入和移出都靠拖动，菜单里只保留“解除堆叠”。

〔用户要求 2026-10-29〕入口改用书面表述。本次采用：原“叠成一摞”改为“创建堆叠”，原“拆散”改为“解除堆叠”，撤销入口为“撤销解除堆叠”。画板保留原文案，应用及本节以新文案为准；交互不变。

- **创建堆叠**：多选两样以上时，动作条出现“创建堆叠”。类型可以混合。普通拖动时卡片互相重叠，不会自动成堆。
- **收起时的样子**：
  - 最上面显示最后加入的那一样，按它自己的尺寸绘制；
  - 后面两层轮廓分别错开 6px、12px，填充为白色 0.16／0.10 透明度，轮廓为 0.5px 白色 0.28 透明度；
  - 右上角放一个中性色数量徽章：高 22，玻璃底 `rgba(60,60,66,0.88)`，白字 12px 中粗，不用彩色。
- **整摞操作**：
  - 单击选中整摞，选中样式同普通卡片；拖动时整摞一起移动。
  - 拖出画布、导出、删除、清空，都按其中每一份材料分别处理，沿用 9.10 的保护和计数。
- **加入**：拖着一张卡片停在堆上约 0.5 秒，堆出现白色光环（2px 白色加 6px 半透明外晕），这时松手即加入。停留不到 0.5 秒就松手，只是普通摆放。
- **展开**：双击整摞，在堆的上方弹出玻璃托盘。双击整摞不会打开最上面那份材料。
  - 托盘宽 332、圆角 18，材质同回答卡片；下方有小三角指向堆。
  - 〔用户确认 2026-10-29〕堆上方空间不足时，把托盘移入可见区域，指示三角仍指向堆。
  - 顶行左侧显示“N 样”，右侧是“解除堆叠”。
  - 成员按每行 3 个、每格 96×80 的网格排列。
  - 画布其余部分压暗（`rgba(10,10,14,0.25)`），堆本身变淡。
- **托盘里**：成员可以选中、处理、拖出。拖到托盘外面即移出这一摞，落在松手处，按 9.9 找空位。点托盘外面或按 Esc 收起。展开状态不保存。
  - 〔用户确认 2026-10-29〕只有拖回画布才移出堆；拖到 Finder 只复制导出，保留堆内成员。
- **解除堆叠**：只解除成员关系，材料都留在画布上，在原堆附近按 9.9 找空位铺开。可以用 ⌘Z 撤销一次。
- **只剩一样时**：堆自动解散，成为普通卡片。

### 9.17 网页预览与空格预览（第五阶段，`LinkPreview`）

〔用户确认 2026-10-29〕链接卡要显示真实网页的缩略截图，标题和网站名也保留，一眼想起为什么收集它；面板上要有类似 macOS 的空格预览：按空格只预览，双击才打开。
〔用户确认 2026-10-30〕三项选择：截图在收进来时自动生成（方案 A）；同意 Dump 联网；统一使用系统预览面板，去掉 Dump 内的播放器。

本节取代 9.3 中链接卡和视频／音频卡“点播放按钮在卡片里播放”的做法，也取代 9.8 末行“链接预览依赖读取能力”的说明。网页正文读取、归纳、内容提取仍不做（见产品简报第 0 节）。

**一、空格与双击（所有材料）**

| 操作 | 行为 |
| --- | --- |
| 单击 | 选中 |
| 选中后轻按空格 | 打开系统预览面板（Quick Look） |
| 预览中再按空格或 Esc | 关闭预览，画布保持原样 |
| 多选后按空格 | 预览面板中用 ← → 逐份查看；堆叠按实际成员 |
| 双击材料 | 用系统默认应用打开 Dump 里的副本；链接用默认浏览器打开原网址 |
| 双击堆叠 | 仍是展开托盘（9.16） |
| 按住空格拖动 | 平移画布，松开后不弹预览 |
| 没有选中时轻按空格 | 不做任何事 |
| 正在编辑文字时 | 空格照常输入 |

- 判定：空格按下后鼠标没有拖动、松开时才算“轻按”，打开预览；按下期间发生拖动就是平移。
- **大预览一律交给系统预览面板**，不自己做查看器：缩放、播放、进度、左右切换都用系统自带的。
  - 〔用户确认 2026-10-30，实际能力验证后〕网页截图预览保留系统原生的“用预览打开”按钮，不定制成画板中的“用浏览器打开”；打开原网址仍从卡片双击或右键“打开”进入。
  - 图片、视频、音频、PDF 和其他文档：直接预览 Dump 里的副本；系统不支持的格式由面板显示文件图标和名称。
  - 文字卡：预览完整文字的副本，可以滚动和选取复制。
  - 链接：预览保存的网页截图，面板标题为“网页标题 — 网站名”。〔用户确认 2026-10-30，真实验收后〕所有没有截图的网址，在系统预览中显示本地的标题、网站名和完整网址说明，不把原 `.webloc` 交给 Quick Look（实测它会自行访问网址，可能消费一次性链接）。生成截图后仍预览截图，双击仍打开原网址；本地说明不作为新材料，也不进入拖出或复制格式。
- 视频、音频卡上的播放按钮保留为标识，点击它等于按空格预览；Dump 不再在卡片里播放。关闭预览或切换到下一份时，由系统停止播放。
- 双击打开的是 Dump 里的副本，在外部应用里修改只影响这份副本，原件不变（与“只存副本”一致）。

**二、链接卡的样子**

- 默认 216×192（9×8 格）：上方截图区占满卡宽、高 120；下方标题（12.5px 中粗，两行以内）和“地球图标 ＋ 网站名”（11px，次要色）。底色沿用 9.3 的 `rgba(58,58,62,0.88)`。
  - 〔用户确认 2026-10-30〕保留已有链接卡尺寸与位置，避免旧布局重叠；只有新收纳链接使用新默认尺寸。旧链接可自行调整或恢复为新默认尺寸。
- 截图从页面顶部开始裁切，保持比例填满宽度，不拉伸。
  - 〔用户确认 2026-10-30〕窄高卡片仍保留整幅网页宽度、顶部对齐；截图下方多出的高度用卡片底色填充，不放大后裁掉左右部分。
- 调整尺寸（9.15）时仍可自由改宽高：文字区固定约 72，其余高度给截图；卡片高度小于 144 时不显示截图，只显示标题和网站名。
- 标题：拖入或粘贴时自带的标题优先；没有就用网页自己的标题；都没有时显示网址。网站名用网页声明的站点名，没有就用域名。图标统一用地球，不额外下载网站图标。
- 选中时下方的蓝色胶囊显示完整网址（等宽字，过长时中间省略），代替其他材料显示的文件名。

**三、截图怎么来**

1. 粘贴或拖入网址时，链接卡立即保存并落在画布上，不等截图，可以继续收集。
2. 后台打开一次网页，生成首屏截图：
   - 固定桌面视口 1280×800，只截首屏；
   - 页面加载完成后再等约 1.5 秒，总时长上限 20 秒；
   - 用独立的临时网页会话，不读取也不保存浏览器的登录状态和 Cookie；
   - 静音，不允许弹窗和下载；
   - 只处理 http、https 网址。
3. 截图随这份链接材料保存在本地，重启后直接显示，不重复访问网站。删除或清空链接时一起删除；不单独算一份材料，拖出、导出链接时仍按第四阶段的格式，不附带截图。
4. **不自动访问的链接**：网址中带有一次性用途的参数或路径时，不自动截图，卡片显示“这类链接不自动打开”和“生成预览”按钮，由用户点击后再访问。判定词（不区分大小写，出现在路径或参数名中）：token、auth、login、signin、sign-in、verify、confirm、activate、unsubscribe、reset、password、magic、otp、invite、code、session。宁可多拦，少拦会让链接失效。
5. 截图里出现 Cookie 提示或弹窗时照原样保留，首版不处理。

**四、状态**

| 状态 | 截图区显示 |
| --- | --- |
| 生成中 | 浅色渐变底、地球图标、“正在生成预览”，底部 2px 进度条；标题未取到时先显示网址；卡片带 1.5px 白色描边表示刚放进来 |
| 已有截图 | 截图本身 |
| 离线，已有旧截图 | 照常显示旧截图，不加标记 |
| 生成失败 | 地球图标、“没能生成预览”、按钮“重试” |
| 需要登录或验证 | 地球图标、“需要登录才能看到”，不提供重试 |
| 不自动访问 | 地球图标、“这类链接不自动打开”、按钮“生成预览” |

所有状态下链接本身都可用：双击用浏览器打开，拖出、复制不受影响。

**五、右键菜单**

链接卡右键依次为：打开、复制、导出副本…、刷新网页预览、分隔线、删除…（尺寸改过时另有“恢复默认大小”）。“刷新网页预览”重新访问一次网页，成功才替换截图和网页标题（自带标题不被覆盖），失败保留旧截图并在卡片上短暂提示。

**六、联网**

〔用户确认 2026-10-30〕Dump 获得联网权限，仅用于生成和刷新网页截图；不向 Codex 发送网页内容，不用于其他用途。

- 删除中：状态框写“正在删除…”加进度条，两个按钮都锁住，红色按钮显示“正在删除…”。这时不响应 Esc 和点弹出层外面。

  - 一批删除是一次操作，撤销时整批恢复：收集区顺序、材料位置、卡片尺寸、堆叠、网页截图都恢复，并回到删除前的当前收集区。
  - 全部删除后自动新建的那个收集区，撤销时如果还是空的、也没改过名，就移除；否则保留。保留下来的可能和恢复的收集区同名，允许重名，不自动改名。〔用户确认 2026-10-31〕
  - 退出管理后，画布上现有的撤销入口撤销的是同一批，两处是同一个撤销记录。
  - 有效期沿用 9.10：只能撤销一次，在下一次清空、删除或退出应用之前有效。

**七、浅色模式**

结构不变，颜色按 9.13 和上文给出的浅色数值：系统蓝 `#007AFF`、系统红 `#FF3B30`，弹出层 `rgba(255,255,255,0.94)`。代表画面是 `CollectionManager` 第 ⑤ 格。

### 9.21 新手引导（`Onboarding`）

〔用户确认 2026-10-31〕新手引导要一步一步、带动画，让人觉得耳目一新、做工精致、细节到位。以下具体方案为〔建议〕。

**何时出现**

- 第一次启动时自动出现，只出现一次；关于窗口里“重新观看新手引导”可以再看。
- 从旧版 Dump 迁移过来、已有收集区的用户，新版第一次启动时不自动出现引导（可以从关于窗口里看）〔建议〕。只有全新安装才自动出现。
- 任何一步左上角都有“跳过”，按 Esc 等于跳过。跳过或完成后不再自动出现。
- 引导在一个临时的示例画布里进行，示例图片、示例便签都只属于引导，结束后全部清掉，不进入任何收集区，不占用用户的撤销记录。
- 不读剪贴板，不申请任何系统权限，不联网。

**整体样子**

- 全屏盖一层 `rgba(8,8,14,0.62)` 暗色；需要指向某处时，用径向渐变挖出聚光灯（半径约 46px，边缘 40px 柔化）。
- 文字在左下：标题 26px 粗体，一句说明 13.5px 次要色；下面是白底胶囊按钮（“继续”，最后一步“开始使用”）和 6 个进度点（当前点拉长为 18px 白色）。每步只有一句话。
- 第 ②③ 步要用户亲手做一次：做到之前“继续”是半透明不可点；做到后它亮起来。第 ④⑤⑥ 步只看演示，直接点“继续”。
- 步与步之间：旧标题向上淡出、新标题从下方 14px 处带 8px 模糊升起，约 0.35 秒。

| 步 | 标题／说明 | 画面与动画 |
| --- | --- | --- |
| ① 欢迎 | “搁这儿”／“看中的东西，先搁这儿。”／按钮“开始” | 屏幕变暗；细线从右边弹性滑入；图标先升起，名字逐字（中文 3 个字、英文 5 个字母）间隔 80ms 依次由模糊到清晰升起；随后说明和按钮淡入。约 1.5 秒 |

| ③ 什么都能丢进来 | “把这张图拖到右边。” | 画面中间出现一张示例图（“试试拖我”）。拖着靠近右边时投放面板长出来；松手后图片缩小落进面板，泛起一圈白光。用户拖自己的文件也算完成，但放进的仍是示例画布，结束时清掉 |

| ⑤ 用完，拖走就行 | “拖到桌面、文件夹或聊天框，就是一份完整的文件。” | 示例图从面板里被拖到桌面，落下时变成带名字（“灵感.png”）的文件图标；面板里原位置留着淡影，表示拖出去的是副本。纯演示，不真的在桌面上生成文件 |

快捷键文字跟随设置里的实际快捷键；用户清除了快捷键时，第 ⑥ 步说明改为“把鼠标移到那条细线上就能打开。”

**动画参数**

- 弹性：`cubic-bezier(0.34, 1.4, 0.5, 1)`（相当于 SwiftUI spring response 0.45、damping 0.75），用于细线探出、便签落下、文件图标出现；其余用 `cubic-bezier(0.25, 0.8, 0.25, 1)`。
- 键帽按下 80ms，抬起 120ms；多键之间间隔 50–60ms。
- 系统“减少动态效果”打开时：所有位移、缩放、模糊改为 0.2 秒淡入淡出，演示步骤直接显示结束画面。
